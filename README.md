# Plateforme fablab — réservation de salles et prêt de matériel

Monorepo : `apps/api` (Node.js), `apps/web` (React), `packages/shared` (types et validations communs), `infra`, `docs`.

- `apps/api` : développé par l'équipe backend.
- `apps/web` : squelette vide, prêt pour l'équipe frontend.
- `packages/shared` : contrat commun entre front et back (types, schémas de validation).
